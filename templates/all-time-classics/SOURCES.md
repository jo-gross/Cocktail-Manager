Status: draft, researched 2026-11-15. Everything here needs a human review before release (see `README.md`).

## 1. Recipe sources (facts)

Ingredient lists, amounts and methods are facts and are not protected by copyright. Amounts come from the **IBA
official cocktail specs** (iba-world.com, retrieved 2026-11-15), converted from ml to cl. Historical notes were
checked against the linked English Wikipedia articles. **No text was copied** from IBA, Wikipedia or anywhere else:
all descriptions and history notes in `content-draft.json` are original texts written for this template.

## 2. Images

All images come from **Wikimedia Commons**. For every file, the license, author and source were read from the
Commons API (`prop=imageinfo&iiprop=url|size|extmetadata`) and the file page wikitext (license template,
permission/VRT ticket, Flickr review) on 2026-11-15. Every image was also checked visually: a single drink, no
identifiable people, no prominent logos or brand labels. Files were downloaded as Wikimedia thumbnails. Commons
serves standard thumbnail widths, so a request for 800 px returns 960 px. Smaller originals were downloaded
unchanged. No local edits (crop, recompression, colour) were made. Every file was checked with `file`: all are real
JPEG/PNG rasters, each under 250 KB.
